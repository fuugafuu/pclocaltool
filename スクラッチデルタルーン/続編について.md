# DELTARUNE Scratch 修正版（2026-10-04）

プレイ・編集用は `DELTARUNE_scratch edition_continued.sb3` です。元の SB3 は残しています。Scratch／TurboWarpへ修正版を読み込んでください。ローカル確認用は `プレビューを開く.cmd` を実行し、「続きから」を押します。Node.js が必要です。

| キー | 操作 |
|---|---|
| 矢印 / Z | 移動 / 調べる・会話を送る・決定 |
| X | ダッシュ・会話の文字を一括表示・戻る |
| C | 操作可能な場面でメニュー開閉 |
| Enter | 追加部分へ移る |
| M / N / P | 暗い世界の入口 / 次の部屋 / 前の部屋へ移る |
| O | ルーディン戦を起動 |
| H / J | 判定表示 / 壁抜け。壁抜け中もドアは有効 |
| R / V | 自宅 / 実行中のチェックポイントへ戻る |

緑の旗で状態を初期化できます。R は通学フラグなど全状態の初期化ではありません。永続セーブは未実装です。

冒頭の物語は原作の画像スクロール・切り替え・フェード・文章のタイミングで約129秒間自動再生します。Zで物語をスキップして起床イベントへ進みます。「物語・メニュー・滝を検証」は見える画面でこの区間を再生します。これは全チャプターの完成・全編検証を意味しません。

今回、自宅の左右ドア、浴室の帰り、学校左の教室、入室直後の逆戻り、電話・テレビの調査位置、歩行・ダッシュの更新間隔を修正しました。原作の斜めの壁を含む当たり判定を使用しています。

元の「ドットテキストエンジン改良版」へ会話処理を統合。原作日本語フォント、話者ごとの音、表情、上下の会話枠、改行、選択肢を追加しました。未収録文字は代替描画します。

教室の人物位置、ノエルとの組分け、スージィの入室、チョークを食べる演出、壁へ押し付ける演出を追加。合成アニメーション中は通常のクリスを隠し、解放後は座り姿、通常姿へ戻します。

車への乗り込み、町を通る通学、沿道の住人の手振り、学校到着、トリエルと手をつないで歩く・抱きしめる・別れる演出を追加しました。滝の滑走の終点、影のランサーの退場、揺れる敵の攻撃、ダストの散る演出、グロウシャード入手も修正しています。Cメニューに原作アイコンとパーティ表示を追加しました。

戦闘制御は元の「選択キー管理」へ統合。元の３人のスプライト、攻撃アニメーション、ソウル、行動アイコン、戦闘パネルを使用しています。３人の行動選択、攻撃タイミング、敵の弾幕、被弾、ACT・見逃す・回復・防御・TP、終了後の復帰を追加。弾のクローンが攻撃通知を再受信して増殖する処理を修正しました。

素材はインストール済みの `E:\SteamLibrary\steamapps\common\DELTARUNEdemo` のバックアップデータと音楽から読み込んでいます。原作のインストール本体は変更していません。
