# ローカルのビルド

ビルド.cmd と ビルド.bat は同じ入口です。ダブルクリックでメニューを開きます。進行度・現在の工程・失敗を表示します。

- 1：検証済み物語seedと最新の戦闘/UI修正から本編を更新。途中の修正も反映します。
- 2：現在の本編から全敵エンジンと制作ひな形を同期。
- 3：現在の本編からNEO公開用を生成。コード5MB/素材10MBと形式を確認してからデスクトップへ配置。
- 4：本編・派生版・25MB版をまとめて更新。
- 5：公開用の形式と構造を検証。
- 6：物語を含めた全Python生成処理を実行。時間がかかります。物語側のコードを変更した場合はこちらを使います。

コマンドでも実行できます。

```bat
ビルド.cmd main
ビルド.cmd public
ビルド.cmd all
ビルド.cmd full
ビルド.cmd main --source "途中のプロジェクト.sb3"
```

途中SB3は共有修正を通し、Scratch形式とブロック・素材の整合性を確認してから本編へ置き換えます。検証に失敗した候補は公開しません。既存の本編から派生版も同期します。

現在の進捗は verification/build-progress.json、メニュー全体は verification/build-manager-progress.json にも保存します。mainの生成元とSHAは verification/unified-main.json、NEO公開用の容量は verification/neo-public-size.json で確認できます。

原作のローカル資料や生成用の素材はこの公開フォルダーへ含めていません。ローカル作業用のツール群がある元ワークスペースで実行してください。
