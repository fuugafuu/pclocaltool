# 公開用の操作とプロジェクト整理

## スマートフォン

`特殊戦闘_公開用.sb3` のタイトルは、タッチ操作がオフの状態でもタップできます。

1. タイトルの **せってい** をタップ。
2. **タッチ操作** の行をタップし、オンにする。
3. **キャラ** を選び、**ぶき**・**ぼうぐ１**・**ぼうぐ２**の行で装備を変更。
4. **もどる** でタイトルへ戻り、開始方法をタップ。

設定の行はタップで次の値へ進みます。キーボードでは上下で行、左右で値、Xで戻ります。装備変更は戦闘前だけです。

左の十字キーで選択・移動し、右のボタンで決定・戻る・早送りができます。操作部はメニュー中は上、回避中は下に表示します。回避中は十字キーから指を離さずにずらすと、斜めにも移動できます。指が十字キーの外に出ても、離すまで移動が続きます。**自動射撃** がオンなら、回避中に溜め射撃を繰り返します。標準 Scratch の1点入力で移動と射撃を両立するための補助です。会話は手動で送ります。

音量も「せってい」から変更できます。

## 整理の方針

- 本編で使っていないイベント処理・手続き・孤立ブロックを、呼び出しの到達関係から除去。
- 未読の旧変数を削除。外部から参照する変数、今後の派生版の構築に必要な共有変数は保持。
- 衣装名が固定のスプライトでは、指定されない衣装を削除。動的に衣装を選ぶバンクは保守的に扱う。
- 3人分の選択マトリクスを、元のフレームを使う1つの表示へ統合。
- 公開用の白い味方ハイライトは、人物の衣装を共有するクローンへ統合。
- 公開用の回復対象表示は、名前・バー・数字を部品として共有。HPごとに行全体を画像化する方式を廃止。
- 公開用から通常敵の退場素材、旧デモ文章の自動再生、他の敵・本編専用の処理を除去。

標準 Scratch の SB3 にはスプライトフォルダの保存機能がありません。描画の前後関係を変えず、スプライト一覧を「画面／文字／人物／敵／攻撃／場面／音／制御」の順に整理しています。本編には各スプライトの整理区分コメントも付けています。通常の Scratch で開けない独自フォルダ形式は使っていません。

機械的な削除記録は `verification/legacy-asset-cleanup.json`、公開用は `verification/neo-public-legacy-cleanup.json`。容量は `verification/neo-public-size.json`、実操作結果は `verification/neo-public-runtime.json` と `verification/neo-public-settings-runtime.json` を参照してください。

## 原作との比較範囲

装備の名称、装備可能な人物、AT / DF / MAGIC の補正値は、ローカル原作の Chapter 2 `scr_weaponinfo` / `scr_armorinfo` を読み取ります。所持品画像を新しく描き直したものではありません。

既存の比較・移植範囲は、通常ルートの直前会話、射撃講習、仲間アクション、糸、通常・溜め射撃、心臓の基本波、表示位置、溜めの光などです。比較元は `obj_ch2_sceneex2.Step`、`obj_spamton_neo_enemy.Step`、`obj_heart.Draw` などのローカル書き出しです。

**原作コード全体の完全な移植・全分岐の検証完了を意味しません。** 電話・顔・最後の攻撃の専用制御、心臓の上位難度、全結末、装備固有の射撃形式・グレイズ補正などは比較・実装が残っています。公開用のHPバランスにも既存エンジン由来の値が残っています。原作の生データやコード本文は配布物へ含めていません。
