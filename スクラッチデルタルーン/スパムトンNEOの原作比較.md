# スパムトンNEOの原作比較

原作のローカルデータから、通常ルートの導入・戦闘画面・攻撃の呼び出しを比較した。以下の名前は照合元のオブジェクトまたはスクリプトを示す。

- `obj_spamton_neo_enemy.Draw` の姿勢31〜33では暗転の上に目のマーカーが出る。公開用にも原作のプレビュー頭部を使った発光を追加した。
- `obj_ch2_sceneex2.Step` と `obj_encounterbasic.Step` では、カートから戦闘姿勢へ移る。カメラと仲間の座標を同じ基準で切り替え、場面用のルードバスターは本戦に入る時点で停止する。
- `obj_yheart_shot.Other_10` は通常弾の消費時に着弾アニメーションを生成する。射撃講習と本戦に原作の着弾フレームを追加した。
- `scr_gamestart` のChapter 2初期HPはクリス120、スージィー140、ラルセイ100。NEO戦ではこの初期値を使う。原作の本編では進行に応じて最大HPが増える。
- `obj_battlecontroller.Draw` に従い、スパムトン戦の魔法説明は右側、TP消費はその下に置く。カットALLのような協力ACTは必要な仲間の顔を先に出す。原作で説明が空欄の行動はそのまま空欄にする。
- `scr_monstersetup` の通常NEO（モンスター50）にレッドバスターはない。Chapter 2ではクイーン（モンスター48）の協力ACTにある。

| 攻撃 | 原作の呼び出しと今回の対応 |
| --- | --- |
| 飛び頭・隊列・心臓 | 飛び頭0、隊列6、心臓1.5。既存の移植を使用。心臓の上位難度は別途比較が必要。 |
| 電話 | `obj_sneo_phonecall` は通話後にFootball Pipisへつなぐ。現在の簡易弾幕はその専用処理と異なる。 |
| 電話の手 | 8.5。単発のランダム発射をやめ、原作の拡散弾の120・180・240度に合わせた。上下の手、中央の親機、難度差の動きは引き続き比較が必要。 |
| 顔 | 原作は専用コントローラー12で顔の部位を出す。部位別の制御は未移植。 |
| 最終攻撃 | 原作9は歪んだ枠、最終形態、ドル弾を順に生成する。現在の簡易弾幕は専用処理と異なる。 |

原作コードと生データは配布ファイルへ収録していない。
