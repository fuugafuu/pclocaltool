# 戦闘エンジン・制作ひな形

`戦闘エンジン_制作ひな形.sb3` は、本編と共通の戦闘処理・キャラ・コマンド・枠・命中画像・効果音・BGMを使う編集用の別版です。テスト敵には原作のマネキン画像を使用しています。全7種の対戦用ファイルは `戦闘エンジン.sb3` です。

## 最初の操作

ScratchでSB3を読み込み、緑旗を押します。黒い下地と元の戦闘背景の上で、中央にいるキャラが10フレームで配置へ移動し、15フレームの構えへ移ります。原作の移動用・入場用画像と残像を使用します。

矢印でコマンド・対象を選び、Zで決定、Xで戻ります。回避中は矢印で移動、Xで低速移動。Rで最初からやり直せます。勝利文はZで進めます。

## リストで変える

ステージの「変数」から、次の `制作・` リストを編集してください。変更後に緑旗かRで再開始します。

| リスト | 内容 |
| --- | --- |
| 制作・敵設定 | 1行目＝名前、2行目＝HP、3行目＝攻撃力 |
| 制作・味方設定 | 3人の開始HP、スージィ参加、ラルセイ参加、スージィ操作（0/1） |
| 制作・セリフ | ターンごとの文章。行を足すだけで追加。`|` で改行 |
| 制作・しらべる | CHECKの説明。`§`で改行。敵名と攻撃力の見出しは敵設定から生成 |
| 制作・アイテム | 1行に1個、最大12個。1＝ダークキャンディ、2＝復活ミント、7＝スピンロール、8＝ダークバーガー。同じ番号も個別枠 |
| 制作・攻撃順 | 0＝通常のダイヤ弾、1＝縦の攻撃。最後まで行くと先頭へ戻る |
| 制作・攻撃時間tick | 攻撃順と同じ行数にする。30tick＝1秒。1以上の数値 |
| 制作・BGM | `戦闘` または `BGM:jevil`。元の曲を収録 |

文字描画用の `制作・文字` と `制作・文字幅` は対応表なので、通常は変更しません。追加文章の動的描画に使用する文字バンクは戦闘用 `fnt_ja_mainbig` です。未対応文字は `?` になります。

敵名の対象選択画像は「Chapter1・敵対象選択」の `field:` / `rudinn:` コスチュームにもあります。敵名を変更するときは、ここも同じ名前に変更してください。

## 敵の見た目を変える

「Chapter1・ルディ」は通常敵の処理を流用した内部名です。見える敵はテストダミーです。コスチュームを変更するときは、被弾・見逃し・撃破の画像も合わせます。

- 本体：「Chapter1・ルディ」
- ルードバスターの白い被弾：「Chapter1・ルード命中の白光」の `Chapter1・ルディ:`
- 退場：「Chapter1・原作の敵退場」の `rd:defeat:` と `rd:spare:`

撃破は白い被弾から右への退場、見逃しは別の残像と星です。両方とも同じ敵の見た目で用意してください。内部名やメッセージ名は変えずに、コスチュームを差し替えると安全です。

## 攻撃を増やす

「制作・開始と設定」「選択キー管理」「Chapter1・ルディのダイヤ弾」にコメントを入れています。

1. 攻撃順と攻撃時間tickへ同じ行を追加します。
2. 既存の弾スプライトを複製し、開始条件を新しい番号（2以上）にします。元の2種類は番号2以上では生成されません。
3. `制作・ターン開始` を受け取ったところで、`続編ルディ波` の番号を確認して自作攻撃を開始できます。
4. 座標・速度・当たり判定・グレイズは既存ブロックを参考に変更します。回避状態は `続編戦闘 = 3` です。
5. ターンが終わったらクローンを削除し、無敵中に連続ダメージを与えないようにします。

## 容量と更新

書き出し時に `project.json < 5,000,000 bytes`、各素材 `< 10,000,000 bytes` を検査します。未読の変数と未使用の本編リストを除去しています。画像を差し替える際は、自分の素材の容量も確認してください。

本編を更新した開発者は、`tools/sync_battle_outputs.py --source <最新の本編SB3> --publish-local` を実行すると、同じ本編から対戦用・制作用の両方を再出力できます。構造・容量を確認してからルートとデスクトップを更新します。ゲームを修正した後は実操作の検証も必要です。
