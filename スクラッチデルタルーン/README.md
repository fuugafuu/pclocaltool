# DELTARUNE Scratch

- `DELTARUNE_Chapter1_25MB.sb3`：本編の軽量版。平原のランサー／スージィのイベントとジグソーリィ3体戦まで追加しています。
- `ランサー戦_単独.sb3`：戦闘単体版。難度を選んだ後の設定で、ランサーとモンディ、アイテムの数とセットを選べます。
- `progress.md`：作業履歴と検証結果。末尾が最新です。
- `chapter1_coverage.md`：原作のマップ・イベント・敵・編成を確認するための対応表。収録や静的参照だけでは完成判定にしていません。
- `続編について.md`、`保留中の作業.md`：従来の作業資料です。古い日付の記載は現在の仕様と異なる場合があります。

操作は矢印キー、Zで決定、Xで戻る、Cでメニュー／会話早送り。教室の4択は左・右・上・下で直接選び、Zで確定します。単体版ではRで再挑戦できます。
