# DELTARUNE Scratch

- `DELTARUNE_Chapter1_25MB.sb3`：本編の軽量版。よろず屋前からパズル教室への往復、4人の先生の説明、寄付箱を追加しています。
- `ランサー戦_単独.sb3`：戦闘単体版。難度を選んだ後の設定で、ランサーとモンディ、アイテムの数とセットを選べます。
- `progress.md`：作業履歴と現在の状況。末尾が最新です。
- `続編について.md`、`保留中の作業.md`：従来の作業資料です。古い日付の記載は現在の仕様と異なる場合があります。
