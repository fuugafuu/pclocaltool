# DELTARUNE Scratch

- `DELTARUNE_Chapter1_25MB.sb3`：本編の軽量版。24,912,436bytes。画像・短い効果音を保持し、長い音声を圧縮。
- `戦闘エンジン.sb3`：全7種の敵、通常敵1〜3体、装備・通常/最強セット・アイテム設定。`ランサー戦_単独.sb3`も同内容の互換名です。
- `戦闘エンジン_制作ひな形.sb3`：原作の戦闘画像・フォント・BGMを使う編集用。敵/味方・セリフ・CHECK・攻撃順/時間・所持品をリストで編集。コードは4,912,701bytes。
- `戦闘エンジン_制作ガイド.md`：編集方法と追加攻撃の入口。
- `progress.md`：検証結果と履歴。末尾が最新。
- `残件一覧_非マップ.md`：比較を継続する箇所。
- `chapter1_coverage.md`：マップ・イベント・敵の対応表。収録だけで完成判定にはしていません。
