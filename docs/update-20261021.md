# 2026-10-21 アップデート

## ゲームの描画負荷

- 左右独立の7-BAG生成を維持。
- テトリスの背景・ミノ、リバーシの背景・石をキャッシュして再利用。
- ResizeObserverで描画サイズを更新。描画ループ内のレイアウト取得を廃止。
- HUDは値が変化したときだけ更新。操作・落下・演出は継続して描画し、静止中の再描画を抑制。
- エフェクトOFF時にはテトリスの落下軌跡・消去粒子・攻撃ビームを生成しない。
- Canvasの透過合成を不要にし、描画解像度の上限をDPR 1.5に設定。

Chromium・1500×1080・ソロ・約1.5秒の同条件測定：

| 指標 | 変更前 ON / OFF | 変更後 ON / OFF |
| --- | --- | --- |
| DOM変更回数 | 273 / 273 | 1 / 2 |
| 角丸図形の描画回数 | 4290 / 4368 | 280 / 320 |
| 毎フレームのサイズ取得 | 91 / 91 | 0 / 0 |
| フレーム間隔 p95 (ms) | 18.7 / 17.9 | 17.6 / 17.5 |

これはソロ開始直後の処理量の比較です。端末固有の入力遅延、実際の画面表示までの時間、激しい攻撃中の性能を保証する測定ではありません。計測は `npm run measure:arena` で再実行できます。

## Agent Bridge

- 「プレビューに保持」と「このファイルを保存」を分離。Ctrl/Cmd+Sはファイル単位の保存。
- PCのフォルダを直接選択した場合は実ファイルへ書き込む。他のファイルのプレビューは保持。
- フォルダ読込モードではメモリ保存であることを明示。「ファイルを書き出す」で現在の編集内容をダウンロード。
- 関連フォルダを含む操作はワークベンチでまとめて反映。外部変更を検出した場合は停止。
- 文字列検索・一括置換、行列位置・文字数、開き直しを追加。
- 変更セットの復元、実ファイル保存、検索置換、競合、モバイル表示をブラウザーで検証。

## 共通メニュー

- トップページにも共通データ管理メニューを追加。
- バックアップはキー別の新規・上書き・同じ内容と容量を確認し、必要な項目だけ復元可能。
- オンライン状態・設定容量・オフラインデータの準備状態を表示。
- 各ツールから更新を確認し、準備後は作業を保存して手動で最新版を表示。
- Agentとトップの既存Ctrl/Cmd+K操作を維持。共通メニューはCtrl/Cmd+Shift+Kで開ける。
- メニューを閉じると元の操作要素へフォーカスを戻す。

Scratch作品や作業フォルダ本体は設定バックアップの対象外です。更新では自動的に編集中の画面を再読込しません。
