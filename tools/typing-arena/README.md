# Typing Arena — Adaptive Typing Trainer

PC Local Toolに追加されたブラウザ完結型のタイピングトレーナー。

## 機能
- 日本語ローマ字 / 英語。日常・技術・物語・科学・全ジャンル。
- 通常ランダム出題 / AIコーチ出題（独自のローカル適応アルゴリズム）。
- 5段階の基本難易度、AIの学習強度（やさしく補助 / バランス / 苦手を重点）。
- 30・60・120秒 / 時間無制限。
- 7種ほどのローマ字表記ゆれ（shi/si、chi/ti、tsu/tu、sha/sya 等）、小さい「っ」、撥音「ん」に対応。
- 任意の組合せで新しい文章を作るため、固定問題を巡回し続ける方式ではない。完全に重複しない保証や、あらゆる日本語のローマ字表記の完全網羅を意味しない。
- キー入力ごとの正誤と所要時間（移動平均）、苦手キー、二文字組、正確率、CPM/WPM、コンボ、成績評価。
- 最近80セッションの記録、速度チャート、キー別ヒートマップ、成績のJSONエクスポート、学習リセット。
- 画面内タッチキーボード、CSSによる軽量アニメーション。音は既定OFF。reduced-motion設定に対応。
- エンジンに外部ライブラリ、クラウドAPI、学習済みLLMは不要。データはlocalStorage保存。

## AIの仕組み
「AI」は生成AIサービスではなく、localStorageに保存した入力履歴から弱点文字を推定し、候補文を局所的に評価して再ランキングする適応型アルゴリズムです。
- 各文字・直前文字とのペアについて正解・ミス・打鍵間隔の滑らかな推定値を蓄積。
- 候補文22件から苦手文字が多い文と直近に出ていない文を優先。
- 最近6セッションの正確率と速度で出題文の長さを±1段階調整。
- 「苦手を重点」モードではさらに候補集合を広げる。

## 測定について
CPM = 正しく受理された打鍵数 / 経過分。WPM = CPM / 5。正確率 = 正しく受理された打鍵数 / (正しく受理された打鍵数 + ミス)。
**正しいキーを入力するまで進まない仕様**。Backspaceで直前の確定入力を戻せますが、学習済みの苦手判定は残ります。
日本語IMEの変換結果を解析するモードではなく、物理キーまたはタッチキーボードによる直接ローマ字入力です。

## 開発
`engine.js` はNode.jsで読み込み可能。ユニットテストは `tests/typing.test.cjs` を参照。

## プライバシー
外部送信なし。成績保存を削除するには画面の「学習履歴を初期化」を使用してください。ブラウザのサイトデータ消去でも削除されます。
