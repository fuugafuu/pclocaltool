# Math Assist Final

PC Local Tool のローカル計算アシストです。`index.html` をブラウザで直接開いて使えます。外部API・CDN・サーバーは不要で、入力した式やデータは外部送信しません。

## 主な機能

- かんたん入力：数式、文章、表、連立方程式、関数、組合せなどを判定して適切な計算へ誘導
- 数式：四則演算、括弧、累乗、平方根、三角関数、対数、絶対値など
- 厳密計算：分数・有限小数を BigInt ベースの有理数として正確に計算
- 数論：最大公約数、最小公倍数、素因数分解、平方根の簡単化
- 文字計算：比較、差、倍率、割合、速さ・時間・距離、平均、比較文判定
- 方程式：1変数の一次・二次方程式、2〜4変数の一次連立方程式
- 代数：整数係数二次式の因数分解
- 関数：グラフ、指定点の値、数値微分、零点探索、数値積分
- 図形：基本平面・立体図形の公式計算と逆算、三角形の辺・角・面積・周長
- データ：合計、平均、中央値、四分位数、分散、標準偏差、最頻値、棒・折れ線・円グラフ
- 確率：基本確率、順列 nPr、組合せ nCr、階乗
- 行列：加減算、積、転置、行列式、逆行列（最大6×6）
- 単位換算：長さ、面積、体積、質量、時間、速さ、データ量、角度
- 履歴：ブラウザの localStorage に端末内保存

## 使い方

1. `tools/math-assist/index.html` を開く。
2. 迷った場合は「かんたん入力」にそのまま入力する。
3. 候補が複数ある場合は目的を選ぶ。
4. 専門計算では各タブから入力する。

## 設計方針

自動判定が曖昧な場合に勝手な答えを確定しないことを優先しています。通常計算は実数の数値計算、厳密分数・組合せなど整数性が重要な計算は BigInt 系エンジンに分離しています。関数の微分・零点・積分は数値近似です。

## 動作条件

近年の Chrome / Edge / Firefox / Safari。学校PCなどでローカルファイルを開く場合でも動作するよう、モジュール読み込みや外部依存を使用していません。
