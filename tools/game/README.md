# Game / Stack Arena

`index.html` を開いて遊べる、外部ライブラリ・API不要のテトリスアリーナ。
PC Local Toolのホーム画面から「Game / Stack Arena」または「テトリス」コマンドで起動できます。

## モード

- 人間vsAI：5段階の相手AIと1本勝負 / 2本先取 / 3本先取。
- 一人プレイ：150ラインのマラソン。開始レベル1 / 5 / 10、10ラインごとに加速。
- AIvsAI：左右のレベルを個別指定して観戦。対戦と同じルール・探索実装。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 / ソフトドロップ | ← → / ↓ |
| 右回転 / 左回転 | ↑ または X / Z |
| ハードドロップ | Space |
| ホールド | C または Shift |
| 一時停止 / 再開 | P または Esc |
| 全画面 | F |

タッチ用ボタンも用意。タブを隠すと自動停止します。
設定変更は新しい試合で反映します。サウンド・演出・ゴーストとソロ最高得点をブラウザに保存します。

## 盤面・対戦

10×20の表示領域と2段の隠し領域。7-BAG、SRS（I専用キック含む）、NEXT 6個、ホールド、
ゴースト、500msの固定猶予、接地後15回までの移動・回転による固定延長に対応。
両者は同じシードから開始し、AIも合法な移動経路でプレイします。

攻撃表は [TetrisWikiのTetris 99解説](https://tetris.wiki/Tetris_99) を参考にしています。
通常消去・Tスピン・ミニ、REN、B2B、全消し、バッジ倍率、攻撃相殺を実装。
受信上限12段、送信上限20段。3秒の予告後、ラインを消さずに固定すると先頭のおじゃま塊が上がります。
予告メーターは黄→赤に変わり、ラインを消し続けると上昇を先送りできます。

1対1へのアレンジとして、KOで1片＋相手のバッジ片を獲得し、片をラウンド間で引き継ぎます。
2 / 6 / 14 / 30片で攻撃+25 / 50 / 75 / 100%。ターゲットは常に相手1人なので、
99人のターゲット選択・複数被ターゲット補正はありません。詳細な攻撃表は画面の「?」を参照。

## AI

| レベル | 目標配置速度 | 探索 |
| --- | --- | --- |
| Rookie | 0.7 PPS | 1手・判断の揺らぎあり |
| Pilot | 1.3 PPS | 1手・小さな揺らぎ |
| Expert | 2.5 PPS | 2手・幅5 |
| Master | 4 PPS | 3手・幅6 |
| Apex | 6 PPS | 3手・幅12 |

実際の速度は端末性能と探索時間に依存します。
到達可能な配置・回転入れ・ホールドを探索し、穴、穴の上の積み、凹凸、高さ、
端の井戸、火力、連続消去、予告攻撃の相殺を評価します。先読みには表示されたNEXTだけを使います。
Workerで探索し、UIスレッドを分離。file://等でWorkerが利用できない場合は同じ探索へフォールバック。
学習済みモデルや外部通信は使いません。

## ファイルと検証

- `engine.js`：Nodeでも実行可能な決定的ルール・合法配置の探索。
- `ai.js`：Workerとメインスレッド共用のビーム探索。
- `app.js`：入力、ラウンド、描画、パーティクル、攻撃ビーム、ドロップ残像、合成音。
- `style.css`：PC・モバイルのUI。

ルートで `npm test`。AIの100手継続、SRS、Tスピン、攻撃表、相殺・予告・上限を検証します。
ブラウザ検証は `scripts/verify-game.cjs`。開発用にPlaywrightとChromiumを用意し、
`npm install --no-save --package-lock=false playwright` と `npx playwright install chromium` を実行後、
ローカルサーバーを8080番で起動して `npm run test:browser` で実行できます。
`GAME_BASE_URL` でURL、`PLAYWRIGHT_MODULE` でPlaywrightのモジュールパスを変更できます。
画面・状態の成果物は `output/game/` に生成されます。

`window.render_game_to_text()` は盤面・操作駒・予告・得点などをJSONで返します。
`window.advanceTime(ms)` はブラウザテスト用の決定的な時間進行です。
