# Universal Timer

PC Local Tool の完全ローカル万能タイマーです。`index.html` をブラウザで開くだけで使用できます。外部API・CDN・サーバーは不要です。

## 機能

- カウントダウン：文字時間入力、プリセット、繰り返し、残り時間記録、時間加減算
- ストップウォッチ：1/100秒表示、ラップ・区間記録、コピー
- インターバル：準備・運動・休憩・ラウンド数、最後の休憩有無
- ポモドーロ：集中・短休憩・長休憩・サイクル、完了数と累計集中時間
- 時刻アラーム：複数登録、ON/OFF、毎日同時刻へ自動更新
- 複数タイマー：最大12個を独立して同時実行
- Web Audio APIによるローカル通知音。音量、消音、通知パターンを設定可能
- 全画面集中表示、キーボード操作
- `localStorage` に設定と状態を保存

## 時間入力

例：`5分`、`1時間20分`、`90s`、`12:30`、`01:02:03`。

## 精度について

表示の更新回数を数えて時間を進めるのではなく、終了予定の実時刻 (`Date.now()`) との差から残り時間を再計算します。そのため、ブラウザが一時的に描画を遅らせても表示上のズレを補正できます。

ただし、OSがPCをスリープさせている間やブラウザがバックグラウンド処理を強く停止した場合、音をその瞬間に鳴らすことは保証できません。復帰後には期限切れを検出します。時刻アラームはページを閉じると動作しません。
