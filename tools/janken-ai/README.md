# Janken AI Lab

完全ローカルで動く、プロフィール学習型じゃんけん分析ツールです。

## 対応モード

- 1対1
- 1対1対1（3人じゃんけん）
- あいこ判定
  - 全員同じ手
  - 3人でグー・チョキ・パーが全部出た場合
- 3人戦で同じ勝ち手が2人いる「共同勝ち」にも対応

## プロフィール

参加者ごとにプロフィールを作成し、各プロフィールへ独立して手の履歴を保存します。

保存項目:

- 名前 / アイコン / メモ
- 出した手
- 各ラウンドの勝ち / 負け / あいこ
- 対戦文脈
- 学習用イベント履歴

データは localStorage に保存され、外部送信しません。

## 独自予測エンジン

単純な出現率だけではなく、複数の特徴を重み付きで合成します。

- 全期間の手の分布
- 直近を強く見る時間減衰分布
- 前回その人が出した手からの次手遷移
- 相手側の前回手に対する反応
- 勝ち / 負け / あいこ後の変化
- 直近2手パターン
- 同じ手の連続傾向
- 学習件数と分布の偏りから確信度を算出

1対1対1では2人の相手の予測分布を組み合わせ、グー / チョキ / パー各候補について全9通りの相手手組み合わせを評価し、期待効用が最大になる手を推奨します。

AI戦略:

- バランス
- 負けにくさ重視
- 勝ち狙い

## ラウンドの流れ

1. 自分プロフィールを選ぶ
2. 相手プロフィールを1人または2人選ぶ
3. AIが推奨手を表示
4. 実際にじゃんけんする
5. 全員が出した手を選択
6. 勝敗 / あいこを自動判定
7. 各プロフィールへ個別に学習
8. 次の推奨手を再計算

## 強化版学習モデル

現在の予測は以下をアンサンブルします。

- 全体傾向
- 直近を重視した時間減衰傾向
- 現在の試合だけの傾向
- 1対1 / 3人戦ごとの傾向
- 特定プロフィールとの直接対戦傾向
- 前回手からの次手遷移
- 「同じ手 / 相手に勝つ手 / その他」への変化傾向
- 自分が前回出した手への反応
- 勝ち / 負け / あいこ後の変化
- 2手 / 3手 / 4手のN-gramパターン
- 同じ手の連続傾向

各モデルはサンプル数と分布の偏りに応じて自動的に重みを変えます。少数データだけで強く決めつけないよう平滑化しています。

### 3人戦の相関補正

同じ2人の相手と3人じゃんけんを繰り返した場合、相手Aと相手Bを完全に独立とは扱いません。
過去に2人が同時に出した手の組み合わせを学習し、データ量に応じて最大72%まで経験的な同時分布を反映します。

### AI自己評価

強化版以降のラウンドでは、実際に手が出る前の予測分布を保存します。

- TOP予測命中率
- 実際に出た手へ割り当てていた平均確率
- 現在のモデル確信度
- 特定相手との専用学習件数

をプロフィール分析画面で確認できます。

## 自動適応モード

「自動適応」では、AIの確信度に応じて内部戦略を切り替えます。

- 低確信度: 負けにくさを優先
- 中程度: バランス
- 高確信度: 勝ちを狙う

データがほぼ無い場合には、同点候補を固定し続けないように初期提案も分散させます。

## クイック学習

プロフィール一覧の「過去の手でクイック学習」から、過去に出した手をまとめて追加できます。

対応例:

- グー チョキ パー グー
- ✊ ✌️ 🖐️ ✊
- R S P R

勝敗情報が無い履歴でも、出し手頻度・遷移・N-gram学習に利用されます。

## 対戦復元

進行中の試合は localStorage に保存します。
ページを再読み込みしても、参加者・モード・戦略・ラウンド履歴を復元して続行できます。
