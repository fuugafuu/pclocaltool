# Janken AI Lab

完全ローカルで動く、プロフィール学習型じゃんけん分析ツールです。

## 対応モード

- 1対1
- 1対1対1（3人じゃんけん）
- あいこ判定
  - 全員同じ手
  - 3人でグー・チョキ・パーが全部出た場合
- 3人戦で同じ勝ち手が2人いる「共同勝ち」にも対応

## プロフィール

参加者ごとにプロフィールを作成し、各プロフィールへ独立して手の履歴を保存します。

保存項目:

- 名前 / アイコン / メモ
- 出した手
- 各ラウンドの勝ち / 負け / あいこ
- 対戦文脈
- 学習用イベント履歴

データは localStorage に保存され、外部送信しません。

## 独自予測エンジン

単純な出現率だけではなく、複数の特徴を重み付きで合成します。

- 全期間の手の分布
- 直近を強く見る時間減衰分布
- 前回その人が出した手からの次手遷移
- 相手側の前回手に対する反応
- 勝ち / 負け / あいこ後の変化
- 直近2手パターン
- 同じ手の連続傾向
- 学習件数と分布の偏りから確信度を算出

1対1対1では2人の相手の予測分布を組み合わせ、グー / チョキ / パー各候補について全9通りの相手手組み合わせを評価し、期待効用が最大になる手を推奨します。

AI戦略:

- バランス
- 負けにくさ重視
- 勝ち狙い

## ラウンドの流れ

1. 自分プロフィールを選ぶ
2. 相手プロフィールを1人または2人選ぶ
3. AIが推奨手を表示
4. 実際にじゃんけんする
5. 全員が出した手を選択
6. 勝敗 / あいこを自動判定
7. 各プロフィールへ個別に学習
8. 次の推奨手を再計算
