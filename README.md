# PC Local Tool NEXT

ブラウザで使える7種類のツールをまとめたローカル優先の作業環境です。
`index.html` を開くと、検索・お気に入り・最近の作業から各ツールへ移動できます。

| ツール | 用途 |
| --- | --- |
| Math Assist | 数式・方程式・図形・統計・グラフ（三角関数は度数法） |
| Universal Timer | タイマー・ストップウォッチ・アラーム・ポモドーロ |
| Dev OS Lab | 仮想デスクトップ・OS実験 |
| Agent Bridge | JSON指示によるローカルファイル操作 |
| Janken AI Lab | じゃんけんの傾向学習と予測 |
| Retro Arcade Lab | 200種類のゲーム |
| Scratch Lite | Scratch作品の読込・再生・保存 |

## 起動

ファイルから直接 `index.html` を開けます。一部の機能やオフライン保存を使う場合は、
このディレクトリで `python -m http.server 8080` を実行し、
`http://localhost:8080` を開いてください。GitHub Pages等のHTTPS配信にも対応します。

初回アクセスでは全ローカルアセットを保存します。ダウンロードが完了した後は、
通信を切っても各ツールを起動できます。新しいリリースはService Workerの更新で反映されます。
外部のScratch作品・プレイヤー等は別途通信や事前保存が必要です。
データはブラウザの保存領域に保存され、別ブラウザや別オリジンとは共有されません。

## コマンド例

- `５分タイマー`、`1時間30分15秒`：時間を引き継いで開始
- `2x+5=15`、`cos(60)`：Math Assistへ数式を引き継ぐ
- `ストップウォッチ`、`ポモドーロ`：該当モードを開く
- `Scratch 123456`：指定作品を開く

`/` または `Ctrl+K` でコマンド欄へ移動できます。

## 開発・検証

Node.js 24以上で、追加パッケージのインストールなしで実行できます。

```sh
npm run build:offline
npm test
```

HTML・JS・CSSなどを追加・削除した場合は `npm run build:offline` で
`offline-assets.js` を再生成してください。リリース時には `home-sw.js` の
キャッシュ名も更新します。保存対象の欠落はCIで検出します。
全アセットの保存に成功するまでは新しいWorkerは有効にならず、以前のキャッシュを維持します。
