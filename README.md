# PC Local Tool

学校や共有PCでも、ブラウザだけで使えるローカルHTMLツール集です。

## 第1弾: Math Assist

`tools/math-assist/index.html` をブラウザで開くだけで動作します。外部API・CDN・サーバー通信は使いません。

主な機能:
- 数式計算（四則演算、累乗、平方根、三角関数、対数など）
- 文章/数値入力からの操作候補
- 選択式の文字計算（比較、差、倍率、割合、速さ、平均、比較文判定）
- 一次・二次方程式
- 図形計算と逆算
- 統計（平均、中央値、四分位数、標準偏差など）
- 棒・折れ線・円グラフ
- ローカル履歴

> 三角関数は度数法（°）です。
